Première version publique de **Scripta**, en ligne de commande : la transcription de vidéos YouTube, **entièrement locale**. L'audio est extrait sans télécharger la vidéo, Whisper tourne sur votre machine, et rien de ce qui est transcrit ne la quitte.

## Fonctionnalités

- **Transcription locale** avec whisper.cpp. Les modèles, de `tiny` à `large-v3`, sont téléchargés au premier usage et vérifiés par empreinte SHA-256.
- **Détection d'activité vocale** (VAD Silero), active par défaut : Whisper n'hallucine plus sur les silences et les passages musicaux, et les horodatages restent ceux de la vidéo, au mot près.
- **Formats** `txt`, `srt`, `vtt` et `json`, horodatage au mot compris.
- **Sous-titres YouTube officiels** : `scripta subs`, ou `--prefer-subs` avec repli sur la transcription.
- **Cache** : une vidéo déjà transcrite ressort instantanément, dans tous les formats.
- **Interruption propre** à toute étape (`Ctrl-C`), et codes de sortie documentés pour les scripts.
- **`scripta doctor`** diagnostique l'installation ; **`scripta update-extractor`** met yt-dlp à jour.

## Installation

1. Téléchargez l'archive de votre système, et vérifiez-la avec `SHA256SUMS`.
2. Installez **yt-dlp** et **ffmpeg**, que Scripta invoque sans les embarquer :
   - Windows : `winget install yt-dlp.yt-dlp Gyan.FFmpeg`
   - macOS : `brew install yt-dlp ffmpeg`
   - Debian, Ubuntu : `sudo apt install ffmpeg`, puis `pipx install yt-dlp`
3. Placez `scripta` dans votre `PATH`, puis vérifiez l'installation avec `scripta doctor`.

```console
$ scripta "https://www.youtube.com/watch?v=<ID>"
```

## Limites connues

- **CPU uniquement.** Aucune variante GPU n'est encore distribuée ; elles se compilent depuis les sources (`--features vulkan` ou `metal`), sans avoir été éprouvées.
- **macOS : binaire non signé.** Téléchargé par un navigateur, il est bloqué par Gatekeeper ; retirez l'attribut de quarantaine avec `xattr -d com.apple.quarantine scripta`. Pas de binaire pour les Mac Intel.
- **`--initial-prompt`** n'influence que les premières minutes d'une vidéo : c'est une limite de whisper.cpp, décrite dans la spécification (SF-04).
- Pas encore d'application de bureau.

## Vérifications

Compilé et testé en CI sur les trois systèmes (176 tests). La suite d'acceptation a été exécutée sous Windows, avec le modèle `base`, sur une vidéo de 61 min en français :

- 6,4 × le temps réel ;
- 863 Mo de pic mémoire ;
- 75 % de concordance lexicale avec les sous-titres officiels.
